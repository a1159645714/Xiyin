# XiYin 希音商品自动化上架工具

项目用于从选品结果中选择商品，生成商品标题和商品图片，随后自动完成希音（SHEIN）供应商后台发布页面中的商品信息填写、图片上传、资质选择和发布报名。

## 主要功能

- 以图搜品：选择参考图，在 16 个平台（1688、AliExpress、Alibaba、Amazon、Shopee、TikTok 等）搜索机会商品并展示结果。
- 勾选商品后自动生成发布素材：AI 生成九宫格商品图（优先女性美甲手、儿童手、亲子手把玩商品场景，并强调材质与真实尺寸感）与商品标题（统一整理为标题开头的 `5PCS` 到 `9PCS` 格式，避免出现 `1PCS`）。可在「AI设置」页关闭「AI生成商品图片」，改为直接上传实拍图库「产品图」文件夹的原始图片。
- 实拍图库：扫描「本体 / 包装 / 产品图 / 视频」素材，支持商品直存和颜色/款式变体两种目录结构。
- 店铺画像：内置玩具店、家居店两套类目树与发布类目配置。
- 浏览器自动化：Playwright 驱动 Chrome 完成选品入口、发布类目、主图/视频/详情图上传、标题、必填属性、规格模板、颜色、供方信息、包装信息、资质证书、实拍图、合规信息（欧盟玩具安全指令、产品标识符、美国窒息警告）与发布报名。
- 协作式暂停/继续与停止；单商品失败自动重试最多 3 次，仍失败则记录并跳过，继续处理后续商品。

## 自动化恢复机制

发布当前商品时，如果出现找不到元素、下拉框未打开、上传失败、发布拦截或提交超时等异常，程序会：

1. 记录当前失败步骤和错误信息。
2. 关闭当前发布页面。
3. 返回商品搜索结果页。
4. 重新点击搜索并随机选择「发布同款」。
5. 重新执行当前商品的发布流程。

同一个商品最多重试 3 次。3 次仍然失败时，程序会记录并跳过当前商品，继续处理后续商品。用户主动停止时，流程会立即停止。

## 运行环境

- Windows 10/11
- Python 3.11+
- Google Chrome
- Playwright（浏览器自动化）
- PyQt5 + PyQt-Fluent-Widgets（图形界面）
- Pillow（图片处理）

## 安装依赖

```bash
python -m pip install -r requirements.txt
playwright install chromium
```

## 启动

```bash
python main.py
```

程序启动约 1.5 秒后会检查腾讯云 COS 上的更新清单；版本被停用或存在强制更新时，需要先完成升级才能进入主界面。

## 使用流程

1. 启动图形界面，在「AI设置」页配置 AI 服务与模型；「AI生成商品图片」「AI生成商品标题」「AI生成图片 PROMPT」可分别开关（关闭生图后不要求填写图片 Token，关闭标题/PROMPT 后不要求对话 Token）。
2. 在「选品搜图」页选择参考图与目标平台，开始搜图。
3. 在结果列表中勾选需要上架的商品。
4. 在「上架设置」页选择商品总目录与 Cookie 文件，配置商品属性、证书与实拍图库。
5. 在「执行中心」页开始生成并上架，可随时暂停或停止。
6. 出现异常时，程序会保留日志并自动恢复当前商品的发布流程。只有用户主动停止或浏览器、登录状态等系统级问题无法恢复时，任务才会结束。

## 商品目录约定

商品总目录建议包含：

```text
商品总目录/
  商品配置.json
  商品视频.mp4 或任意 .mp4 文件
  1/ 2/ 3/ ...         数字图片文件夹（轮播图，优先文件名含“主图”的图片）
  本体/                 实拍图
  包装/                 包装实拍图（可选）
```

商品标题、必填属性、包装信息、供方信息、颜色配置、证书列表等均从 `商品配置.json` 读取，字段约定示例见 `开发进度.md`。

## 重要目录

- `unified_gui.py`：PyQt5 图形界面、设置持久化与更新检查。
- `task_workers.py`：后台线程、AI 生成流水线与发布编排。
- `automation.py`：Playwright 浏览器自动化与完整发布流程。
- `image_services.py`：AI 九宫格生成、裁剪与图片下载。
- `ai_content_service.py`：对话模型标题生成与标题规范化。
- `协议AI.py`：AI 服务配置与九宫格提示词。
- `aiprice_image_search.py`：AliPrice 图片搜索接口复现。
- `update_service.py` / `updater_main.py`：热更新检查、下载校验与替换重启。
- `build_windows.bat`：Windows 打包并自动发布到腾讯云 COS。

## 打包与热更新

- 双击 `build_windows.bat` 打包主程序与更新器，并上传 COS 热更新包；加 `--no-upload` 仅本地打包。
- 发布新版本前先在 `config.py` 提高 `APP_VERSION`。
- 发布清单支持 `minimum_supported_version`、`disabled_versions`、`force_update` 等版本策略字段。
- 更新包下载后校验 SHA-256，由 `XiYinUpdater.exe` 在主程序退出后替换文件并自动重启，失败自动回滚。
- 详见 `Windows打包说明.md`。

## 注意事项

- 运行前需要准备有效的登录 Cookie 或已登录的 Chrome 会话。
- 商品目录应包含主图、视频、详情图和对应的实拍图目录。
- 发布页面文字和控件可能随希音页面更新而变化。
- 自动化日志会记录失败步骤、重试次数和最终处理结果。
