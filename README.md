# Xiyin

希音商品自动化上架工具。项目用于从选品结果中选择商品，生成商品标题和商品图片，随后自动完成希音发布页面中的商品信息填写、图片上传、资质选择和发布报名。

## 主要功能

- 根据选品结果选择需要处理的商品。
- 在上架设置中单独启用或停用商品，支持商品颜色和款式变体。
- 使用本地实拍图或 AI 生成商品素材。
- 使用对话模型生成商品标题和九宫格图片提示词。
- 标题数量统一整理为标题开头的 `5PCS` 到 `9PCS` 格式，避免出现 `1PCS`。
- 九宫格图片优先生成女性美甲手、儿童手和亲子手把玩商品的场景。
- 九宫格提示词会同时强调当前材质、真实尺寸感和做了美甲的女性手，避免商品显得过小或只出现普通手。
- 自动上传主图、视频、详情图和实拍资质图片。
- 自动填写商品属性、规格、颜色、供应商和包装信息。
- 自动处理欧盟玩具安全指令等合规信息。
- 实拍图上传弹窗会根据文件类型识别图片上传框，不依赖固定的 `.png` 选择器。

## 自动化恢复机制

发布当前商品时，如果出现找不到元素、下拉框未打开、上传失败、发布拦截或提交超时等异常，程序会：

1. 记录当前失败步骤和错误信息。
2. 关闭当前发布页面。
3. 返回商品搜索结果页。
4. 重新点击搜索并随机选择“发布同款”。
5. 重新执行当前商品的发布流程。

同一个商品最多重试 3 次。3 次仍然失败时，程序会记录并跳过当前商品，继续处理后续商品。用户主动停止时，流程会立即停止。

## 运行环境

- macOS
- Python 3.10+
- Chrome
- Playwright
- PyQt5

## 安装依赖

```bash
pip install -r requirements.txt
playwright install chromium
```

## 启动

```bash
python3 unified_gui.py
```

## 使用流程

1. 启动图形界面并配置商品目录、Cookie 和 AI 服务。
2. 选择平台并执行搜图。
3. 在结果列表中勾选需要上架的商品。
4. 在“上架设置”中确认商品和变体的启用状态。
5. 配置发布类目、商品属性、资质和实拍图目录。
6. 开始生成并上架。

出现异常时，程序会保留日志并自动恢复当前商品的发布流程。只有用户主动停止或浏览器、登录状态等系统级问题无法恢复时，任务才会结束。

## 重要目录

- `unified_gui.py`：图形界面和上架配置。
- `task_workers.py`：图片生成和后台任务线程。
- `automation.py`：浏览器自动化、商品填写和发布流程。
- `ai_content_service.py`：标题和图片提示词生成。
- `协议AI.py`：九宫格图片提示词和协议相关 AI 逻辑。
- `config.py`：页面文字、默认配置和自动化参数。
- `product_files.py`：商品图片、视频和配置文件管理。

## 注意事项

- 运行前需要准备有效的登录 Cookie 或已登录的 Chrome 会话。
- 商品目录应包含主图、视频、详情图和对应的实拍图目录。
- 发布页面文字和控件可能随希音页面更新而变化。
- 自动化日志会记录失败步骤、重试次数和最终处理结果。
